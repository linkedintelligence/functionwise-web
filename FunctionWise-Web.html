Up and running in four steps.

  1. Install Ollama, the free app that runs AI models locally.
  2. Open a terminal and run ollama pull qwen3:0.6b. It's a small download.
  3. Download FunctionWise.html from the project page.
  4. Double-click the file and look for the green "Ollama ready" dot. Type a problem and press Enter.
